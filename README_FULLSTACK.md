# CarbonKisan Full Stack
Your supplied React/Vite frontend is included unchanged except registration/login/store integration for the API. Backend and SQLite database are included.

## 1 Backend
cd backend
npm install
npm run dev

## 2 Frontend (new terminal)
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:5000/api/health

SQLite is created automatically at backend/data/carbonkisan.db.
Demo admin: admin@carbonkisan.demo / admin123
